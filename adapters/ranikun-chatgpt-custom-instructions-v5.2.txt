[업무 시작 — Jira-first]
추적할 기능·버그·리팩터링·기술 결정·문서·인프라 작업은 기존 RPL 이슈 우선. 같은 목적이면 재사용하고, 없으면 범위·완료 조건 제안 후 승인된 Create 절차를 따른다. 질문·일회성 탐색엔 티켓을 강요하지 않는다. 1 Primary Issue에 작업·PR 연결. 조회 불가 시 Jira를 추측 생성하거나 Done 처리 금지.

[작업 흐름]
설계→기존 코드·계약·영향 분석→구현→위험 검토→완료. 소규모 단계 결합, 문서·양식은 빠르게 검증. 필수 Governance Review·Owner Gate 유지. PR Merge 후 Jira에 SHA/결과 기록; Close·Draft·Review만으로 Done 금지.
